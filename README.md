# Projeto de IC: Análise de Séries Temporais Multivariadas do Mercado Imobiliário
## Aluno: Pedro de Moraes Machado | Orientadora: Prof.ª Tardelli Ronan Coelho Stekel

Este repositório contém todos os scripts, notebooks e dados relacionados ao projeto de Iniciação Científica sobre a análise e previsão do mercado imobiliário em Jacareí, desenvolvido no IFSP - Campus Jacareí.

---

## 🎯 Escopo do Projeto

Esta seção define os limites e as principais características da análise.

* **Região Alvo:**
    * **Cidade:** Jacareí, SP.
    * **Nível de Granularidade:** Análise a nível de **bairros**, se a qualidade dos dados permitir. Caso contrário, a análise será consolidada para **São Paulo, SP**.

* **Fontes de Dados:**
    * **Dados Imobiliários:** Web scraping dos seguintes portais:
        * [Zap Imóveis]
    * **Dados Macroeconômicos:** APIs públicas:
        * **Banco Central (SGS):** Taxa SELIC, IPCA.
        * **IPEADATA:** Dados socioeconômicos
